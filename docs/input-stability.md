# 输入稳定化与 AI 工作台（开发中）

本轮基于 `94b4031`，在 `codex/input-stability` 开发。用户要求完成两端长句、候选、响应和设置保存，再完善外观与 AI；同时补齐 Windows AI。先完成源码和验证，不在中途生成安装包。版本仍为 0.6.5，尚未发布新版本，不能将旧安装包作为本轮交付。

## 输入与候选

- 候选查询缓存只在查询真正完成后发布。取消或失败的查询不会把空结果缓存成成功，也不会覆盖后来的输入。
- 学习词频在锁内读取快照和更新，查询复用只读频率表，避免每个按键复制整张表。学习与清空遵守相同锁顺序，避免冷加载与学习并发时重复计数。
- 输入达到单次组合上限时保留后续按键，等待当前候选完成后继续处理。上屏使用回执；宿主拒绝时保留草稿，明确重试，不提前学习或静默丢字。前半段成功、后半段失败时，只恢复未接受的尾段。
- 原生组合串结束与后续草稿在同一个写入会话里处理。切换输入框立即分离旧组合串，迟到的清理和定位回调只能处理原对象，避免影响新输入框。

## 设置和本地历史

伴侣程序和原生设置采用同一旁路文件锁。写入前重读最新文件，只合并本次修改的字段，保留未知字段、注释及既有格式。先写入同目录临时文件并同步，再原子替换；失败显示错误，保持原文件。运行状态与事件在持久化成功后发布。

伴侣前端顺序提交最小修改，首次读取失败时禁止默认值覆盖用户配置。皮肤切换保留系统／浅色／深色选择。旧全量保存接口保留兼容：带版本指纹的陈旧写入会被拒绝；不带指纹的旧接口仍有兼容性限制。已经驻留的旧 TSF/伴侣不遵守新锁协议，不声称解决新旧进程同时写盘的问题。

剪贴板历史取消无序后台快照写入；同一进程内持锁完成原子替换。置顶、删除和清空失败时恢复列表，不显示假成功。损坏或不可读的历史文件不会被空列表覆盖，界面会显示读取／保存错误。共享协议和用户已有配对不变；历史并非跨多个伴侣进程的通用合并数据库。

## AI 工作台

默认关闭。提供语音、帮写、改写、翻译和问答；非翻译功能要求中文，翻译按所选目标语言。结果留在工作台预览，由用户明确复制，不把复制标成已写入其他软件，也不读取其他软件的输入框或屏幕。

文字与语音独立配置和保存密钥。文字支持 OpenAI、Gemini、DeepSeek、火山方舟、硅基流动和兼容接口；语音本轮提供 OpenAI 与 Gemini 的录音结束后转写，不宣称边说边出字或已经实现火山 WebSocket 语音。

官方地址和模型折叠到高级设置，自定义地址自动展开。密钥使用 Windows DPAPI，按用途、服务商和 HTTPS 来源隔离；修改配置发生冲突时保留草稿，要求重新读取。配置已保存只代表本地保存成功，不代表远程服务连通。

录音为内存中的 16kHz 单声道 PCM WAV，最长 60 秒。取消、切换功能或关闭窗口都会停止音轨并取消请求；迟到结果不覆盖新的草稿。流式生成按独立 50ms 节拍刷新，零星尾片不会等下一块网络数据才出现。HTTPS、响应大小、音频长度、取消及固定中文错误经过协议检查；错误不回显密钥或原始服务响应。
